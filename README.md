# 🎨 Diseño con Tailwind CSS

[![Live Demo](https://img.shields.io/badge/Ver_Diseño-En_Vivo-blue?style=for-the-badge&logo=tailwind-css)](https://robertbrito1.github.io/tailwind/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

Este proyecto es una práctica de diseño y maquetación web enfocada en el uso eficiente de **Tailwind CSS**. El objetivo fue crear una interfaz moderna, limpia y completamente responsiva, priorizando la mantenibilidad.

## 🚀 Características principales
*   **Diseño Responsivo:** Implementación de metodología *Mobile-first* para una experiencia óptima en cualquier dispositivo.
*   **Interfaz Moderna:** Enfoque en una UI estética y funcional.
*   **Optimización:** Código limpio y altamente reutilizable.

## 🛠 Enfoque Técnico
Para mantener un código limpio y eficiente, he aplicado las siguientes estrategias:
* **Abstracción de clases:** Uso de directivas para encapsular patrones de diseño recurrentes, evitando la redundancia en el HTML.
* **Configuración personalizada:** Extensión del archivo `tailwind.config.js` con el @apply para estandarizar el sistema de diseño (colores, espaciados y tipografías).
* **Arquitectura modular:** Estructura pensada para facilitar el mantenimiento y la escalabilidad a largo plazo.

## 🛠 Tecnologías utilizadas
*   **HTML5**
*   **Tailwind CSS**
